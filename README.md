📊 Customer Intelligence System
🚀 Overview
This project is an end-to-end Customer Segmentation & Recommendation System that helps businesses understand customer behavior and generate personalized product recommendations.

It combines RFM Analysis, Clustering, and Collaborative Filtering with an interactive dashboard built using Streamlit.

🎯 Key Features
🔹 Customer Segmentation
RFM (Recency, Frequency, Monetary) analysis
K-Means clustering to identify customer segments:
High Value Customers
Regular Customers
At Risk Customers
Low Engagement Customers
🔹 Recommendation System
Personalized product recommendations
Item-based collaborative filtering
Uses customer purchase history
🔹 Interactive Dashboard
Built using Streamlit
Clean card-based UI
Dynamic customer insights
Real-time recommendations
🔹 Business Insights
Actionable recommendations for each segment
Helps in:
Customer retention
Targeted marketing
Cross-selling
🛠️ Tech Stack
Python
Pandas, NumPy
Scikit-learn
Matplotlib
Streamlit
Joblib
📊 Project Architecture
Data → Cleaning → RFM Analysis → Clustering → Similarity → Recommendation Engine → Streamlit UI
